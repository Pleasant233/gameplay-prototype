# 柔和泛光与光圈景深

参考 [《林间小世界》官方画面](https://store.steampowered.com/app/2198150/Tiny_Glade/) 的微缩景观感，加入柔和的高光泛光、前后景虚化和轻暗角。

泛光提取明亮且带颜色的高光，在四分之一分辨率缓冲中进行横向与纵向模糊，低强度合成。白色云团降低提取权重，避免满屏泛白。景深使用真实场景深度与圆形光圈采样；焦点平滑跟随选中地块或操作目标，默认聚焦相机观察中心。

焦点附近保留清晰区域，菜单、文字与收益飞行 Token 由 DOM 绘制，不会被景深处理。菜单中的“氛围开 / 关”可以关闭两种效果，偏好保存在浏览器本地。

桌面 WebGL2 使用 2 次多重采样抗锯齿、18 次光圈采样；手机使用 10 次光圈采样，减小模糊半径并禁用离屏多重采样。渲染分辨率上限分别为 1.5 和 1.25 倍 CSS 尺寸。使用 24 位深度保持细线和水面稳定；不支持深度纹理的浏览器保留泛光。

## 本地验证

使用无头 Microsoft Edge 和软件 WebGL 进行 14 项专项检查，全部通过，无脚本、Shader 或帧缓冲错误。见 [专项报告](atmosphere-report.json)。

固定场景并隔离效果后验证：泛光增加高光亮度，景深改变远景，中心清晰区域像素差为 0；离屏与直接渲染的岩浆表面像素差为 0。检查实际鼠标选择、手机触摸、焦点跟随、开关与偏好恢复，以及多次调整尺寸后纹理数量保持稳定。模拟没有深度纹理的浏览器，确认泛光管线仍可正常运行。

16 项规则检查与地表、云团几何检查通过。手机检查为浏览器视口和触摸模拟，不代表真实手机 GPU 性能；画面仍可根据人工体验继续调整。

开启氛围效果后，28 项整体浏览器回归通过，覆盖放置、选框、收益飞行、结晶免费使用、所有特效回收、重开与手机交互。见 [整体回归报告](atmosphere-browser-report.json)。软件渲染速度较慢，因此特效回收检查允许更长的绘制时间。
