# 云端接续开发说明

本说明将本机 Claude 记忆、原计划和后续已完成的用户要求整理为仓库内的交接材料。云端以当前代码和测试为准，无需访问 `C:\Users\wangs\.claude` 或本机项目外的设计文件。

## 产品方向

单机放置地块游戏，通过地块属性、相邻搭配、生物与轮末产出获得评分和资源收益。使用五行元素，保持方格地图和自由分配行动点的玩法。当前原型没有账号、多人服务或对局存档；刷新会开始新对局。

当前《元素生境》每轮恰好放置 1 块，先放置再施法；初始 3 AP，进度提升后为 5／7／9 AP。地图共 85 格，开局 5 块。灵力由属性和、元素兽×3、元素动物×1、植物×1及愿景奖励组成，元素灵本身不加分。魔法按全图属性解锁，范围净化与 +5 魔法、每 10 轮元素陨石雨、元素盾、地形升级、癌元感染、愿景及本地成就册均须保留。可调规则优先查看 `data.js`，实际状态与合法性由 `game.js` 决定。

## 旧计划与当前实现的区别

本机原计划曾提出圆环、强闪白、更多粒子和重镜头冲击，用户随后要求更自然的卡通画面，所以当前实现减少大面积光环和强闪白。原计划中的“规则不变”也被后续“元素结晶免费”要求更新。不要把旧计划重新当成待办，把这些已经完成或被替代的内容再做一遍。

地形、选择和特效主要在 `view.js`，收益飞行拆成独立 `tokens.js`，后处理拆成 `postfx.js`。浏览器测试的内部探针只在测试请求中注入。

连片区域分析、外围距离场及山脊采样位于 `landscape.js`，只影响视觉。装饰数量与游戏里的植物、生物、资源库存分开；连片提示不代表增加规则奖励。

2026-10-04，首次连片景观发布误用了旧 main，覆盖了此前 CLI 发布的《元素生境》玩法。已恢复此前部署，并从 Vercel 源码快照找回正确基线。后续连片景观基于这份新玩法移植；见 [基线恢复记录](BASELINE-RECOVERY.md)。旧的 `gameplay-prototype.vercel.app` 不属于当前关联项目，仍保留旧版本；后续 main 的发布与验证使用新正式地址。历史发布记录保留原地址。
