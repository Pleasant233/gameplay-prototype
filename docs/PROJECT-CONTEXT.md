## 产品方向

单机放置地块游戏，通过地块属性、相邻搭配、生物与轮末产出获得评分和资源收益。使用五行元素，保持方格地图和自由分配行动点的玩法。当前原型没有账号、多人服务或对局存档；刷新会开始新对局。

原始设计中每轮 3 点行动，至少放置 1 块，地图共 85 格，开局 5 块。灵力评分由地块属性、元素灵、元素兽和元素动物共同组成。可调规则优先查看 `data.js`，实际状态与合法性由 `game.js` 决定。

## 旧计划与当前实现的区别

本机原计划曾提出圆环、强闪白、更多粒子和重镜头冲击，用户随后要求更自然的卡通画面，所以当前实现减少大面积光环和强闪白。原计划中的“规则不变”也被后续“元素结晶免费”要求更新。不要把旧计划重新当成待办，把这些已经完成或被替代的内容再做一遍。

地形、选择和特效主要在 `view.js`，收益飞行拆成独立 `tokens.js`，后处理拆成 `postfx.js`。浏览器测试的内部探针只在测试请求中注入。
