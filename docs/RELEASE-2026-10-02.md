# 元素结晶免费规则与正式发布

## 变更

使用普通和大型元素结晶不消耗行动点，不触发自动换轮，仍消耗对应库存并分别增加 1 或 2 点属性。最后 1 点行动仍可用于放置；其他行动的费用和每轮至少放置一次的规则保持原行为。背包、按钮提示和帮助已注明免费使用。
