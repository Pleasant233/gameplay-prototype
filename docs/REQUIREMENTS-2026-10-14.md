# 2026-10-14 需求对齐

基于拉取后的 `main`（`a01e374`）修改，工作分支为 `codex/requirements-alignment`。沿用远端 80 地块、10 系列、20 分支与 70 条升级关系。没有重新生成另一套地块目录。

## 当前玩法

| 需求 | 实现 |
| --- | --- |
| 1、15 | 挑战模式40轮；每次铺地、施法、刷新及移动守护灵消耗1 AP。一轮可以铺多块，候选立即补齐；AP归零后仍可用免费结晶，玩家点击结束本轮结算。 |
| 2 | 删除木材、矿石、产水、水桶、净化符、采集和相关配方。地块专属功能改成四邻互作；10个系列及其80种地块均有搭配对象。结晶、元素盾和生物生态保留。 |
| 3、4 | 元素兽缩小，用地块坐标和兽ID确定散布位置；同格达到5个立即自动合成守护灵，保留五兽元素配比。轮末自动合兽后也会检查合守护灵。 |
| 5 | 详情直接显示下一层各升级方向、缺项与扣晶数量；选择后自动扣普通／大型结晶。先用普通晶补缺，余量每颗大型晶补2；奇数缺口使用大型晶会多补1属性。T4合兽经历、连片及T5守护灵覆盖条件保留。 |
| 6、7 | 每次星雨掉落1颗对应至纯元素结晶，先以流星轨迹落下，中央放大展示名称与用途，再飞入背包。金／木／水／火／土分别扩展生矿／净化／源泉／焚尽／富庶；每颗增加1格，覆盖1～5格。扩展不代替魔法解锁。 |
| 8、9 | 空地表面和侧壁从紫灰色随当前灵力逐步转嫩绿；上方中央常驻放大的实时公式、下个目标和进度。恢复比例为当前灵力／800，下降时颜色也会回落。 |
| 10 | 属性不足时沿父级升级路线退化，保留实际属性；五项属性都严格小于0时地块消散并成为可重新铺设的空位。0不算负值。 |
| 11 | 魔法对每个覆盖地块播放对应粒子、轨迹、光束或地面反馈；移动端减少粒子，保留减少动态效果偏好和生命周期回收。 |
| 12、13 | 第10／20／30／40轮星雨伤害为3／5／7／9，影响比例逐次扩大。轮末生态及星雨结算后，当前灵力须达到80／220／450／800，未达到立即判负；第40轮达标即胜利。数值集中在 `data.js` 和 `game.js`。 |
| 14 | 沙丘、树林、冰原、海岸、草场、湿地、溪谷、矿山、火山、遗迹分别构建轮廓；等级改变结构数量和尺寸，A/B采用不同地标。80种模型的几何与变换组合互不相同，没有沿用原来的分支色标代替模型。 |
| 16 | 初始85格铺满后解锁完整状态JSON导出、摄影与检视；摄影隐藏经营UI，支持PNG导出、镜头旋转、平移和缩放。既有自动存档继续保存对局，刷新恢复。 |
| 17 | 开局可选无尽模式，也可铺满初始地图后转入。无尽不检查40轮及阶段失败目标；空位沿已有地图四邻延伸，不限制坐标。底座、拾取、连片、云避让和存档支持外扩；每10轮星雨继续增加2点伤害。 |
| 18 | 常驻灵力公式和目标；升级、结晶扩展、地图工具集中到明确入口。数字1～3选卡，B背包，Enter结束轮次，Esc取消／退出摄影，P摄影，Ctrl+S保存完整地图。保留鼠标拖拽、右键平移和滚轮缩放。 |

## 验证入口

追加需求：可升级地块四边显示金色闪烁光带，贴合实际地表高度。提示使用 `G.upgrades`，结晶不足或升级条件消失时释放光带；减少动态效果时常亮。没有新增玩法状态。

- `npm test`：当前规则、80地块目录、生态、存档、30局完整模拟、地表接缝及云几何。
- `npm run test:ui` / `npm run test:gameplay`：当前需求的桌面、手机真实WebGL交互和截图。
- `npm run test:feedback`：星雨、盾、粒子预算、回收与减少动态效果。
- `npm run test:ground`：底座和侧壁无重叠，前后视角像素稳定。
- `npm run test:crystal`、`npm run test:atmosphere`：免费结晶及原有后处理回归。

原v1／v13交互命令现运行当前需求测试，旧的“一轮一块”“手工选五兽”“材料采集”等断言已被对应的新规则断言替换。测试探针只由测试服务器注入，游戏没有新增调试API。

18项需求的初次浏览器检查共103项（需求26、反馈29、底座25、结晶9、后处理14），均通过且无浏览器错误。追加升级提示后，完整需求回归通过26项，手机粒子检查因测试时钟暂停而超时；推进时钟后，桌面／手机的粒子回收和阶段失败4项定向重测通过，覆盖余下检查。没有将首次超时运行记为整套通过。新版报告写入忽略的 `artifacts/`，没有覆盖历史发布结果。软件WebGL及手机模拟不能代替实机性能或美术接受度确认。

已发布存档继续恢复；旧存档超过40轮时转为无尽，原铺满结束的存档可继续无尽。升级大型结晶补充的额外1点仍须满足属性上限。
