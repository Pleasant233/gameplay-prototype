# 元素生境 v1 策划比对与实现

本次以桌面文件 `元素生境_玩法策划案v1.0.docx` 的实际内容为依据，将旧版灵地复苏原型更新为元素生境 0.2.0。仍是离线静态网页、85 格方形地图、明亮卡通微缩景观；云海、连续地形、Bloom、景深与收益飞行保留。

用户确认的基础灵力公式：**全图属性和 + 元素动物×1 + 元素兽×3 + 植物×1**。元素灵本身不计分。愿景目标各奖励 30 分，单独展示；成就无额外属性或分数奖励。

| 项目 | 原型旧版 | 本次实现 |
| --- | --- | --- |
| 地形 | 单格属性上限 9，无主动升级 | 同种四邻连片 N 格，上限 9+3×(N−1)；满足更高阶地形逐维门槛可免费升级 |
| 魔法 | 开局全部可用、一般 +1、净化单格 | 净化开局解锁、负属性 +5、选中及四邻；其余全图对应属性≥20解锁、+5；矿脉/泉眼/耕田标记 |
| 污染 | 仅负属性 | 癌元按负属性生成；三轮吸收非零对应属性并产逆结晶；随机移邻并感染原地元素灵；净化/焚尽消灭 |
| 元素兽 | 三灵合兽、两轮大型结晶、自行移动 | 保留；新增玩家移动和移入地块对应属性 +1 |
| 普通生物 | 宽泛条件、植物最多3/动物最多4 | 按表中每种植物/动物的门槛；每块每轮植物/动物各以1/3概率生成一只候选；上限5株/3只 |
| 元素动物 | 同样产普通结晶 | 每三轮金产随机矿物、木产随机作物、水产一桶水、火/土提升所在地对应属性 +1 |
| 生物交互 | 全部耗1行动 | 免费；移动、配对、喂养、砍伐、堆肥共用每个生物本轮一次的限制 |
| 工具物品 | 桶木1铁1；庇护所木2铜1并加属性 | 桶木1；倒水+1并生小湖、沙漠变绿洲、火山拒绝且不扣水；庇护所木4铁2，元素灵容量+4 |
| 行动阶段 | 固定3点，可多次铺地 | 每轮先铺一块、仅铺一次；灵力达到500/1000/1500提升为5/7/9点；每种魔法每轮一次 |
| 地块供给 | 所有类型随机三张 | 阶段一仅初始值1；后续阶数±1；3颗普通结晶重投全层候选 |
| 灾变 | 无 | 每10轮随机一种元素陨石雨，连通区域floor(地块数/3)格、各−3 |
| 防护 | 无 | 自选普通结晶配比，5的倍数造盾；每5颗覆盖1格，背包中选择部署，共享对应元素防护池 |
| 成就与愿景 | 无 | 12项成就、进度、提示、浏览器本机记录；每局随机2个愿景、奖励分单列 |
| 剧本 | 无 | 荒芜初醒、火脉躁动、水泽污浊；均五格相连、属性和9 |

## 原型采用的解释与可调参数

- “每多一块相邻同种地块”按整个四邻连通片解释。升级时保留属性及物体；若拆开连片导致上限下降，则将超出的正属性裁到新的上限。没有额外增加文档未给出的负属性下限。
- 阶段按**基础灵力历史最高值**提升，灾变不会撤销阶段；愿景奖励不用于阶段升级。达到阶段时当轮补足新增行动点。魔法解锁也会保留。
- 交互限制按每个生物个体，而非全图同物种；同一对象本轮移动后不能再喂养或堆肥，配对会标记两个亲本。物品按普通/大型/逆结晶的元素类别、矿物类别、桶、净化符分别限一次；制造按配方限一次，部署按盾限一次。物品与升级可在铺地前使用，施法需先铺地。
- 结晶重投自动按金、木、水、火、土顺序扣足3颗普通结晶，按钮提示明确显示；三个候选互不重复。大型与逆结晶不用于重投或造盾。
- 元素灵每块每轮按正属性加权生成1个，癌元每块每轮按负属性加权生成1个；生成受本地容量限制，迁入和感染产生的癌元不被删掉。癌元每次移动感染原地1个可用元素灵，移动预先收集，避免同一个体一轮连续跳格。
- 木元素动物随机产生水稻、小麦或玉米。金元素动物产物直接进入背包，水元素动物产出独立装水库存，不要求先造空桶。自然矿物按金属性、可产矿地形或矿脉生成，上限2；矿种采用旧版权重。
- 普通植物和动物各每块每轮至多自然生成1个。配对仍采用旧版3轮冷却；鸟吃鱼、熊吃兔/鱼、豹子吃鹿，在轮末每个捕食者至多吃1只同格猎物。未杜撰生态营养奖励。
- 陨石从随机地块出发覆盖四邻连通区域，取整向下。盾从部署地块向四邻扩展，部署后区域固定；同一盾的各元素耐久在覆盖区共享，按实际抵挡伤害消耗，全部耗尽时移除。可查看盾的剩余元素防护值。
- 策划只说明愿景方向，没有确定分值；本原型设4种目标，每局随机2种、每个30分。成就共12项，具体条件在 `data.js`，与规则和存储分开。
- 七节确认公式中的植物按所有现存植物计算。九节“具体公式待定”由用户本次答复覆盖。约30–45分钟是策划目标，本次自动测试没有验证真实玩家时长或数值平衡。
- `7×7×3(z)+4×9`沿用原型85格平面和三维高度表现，没有另外增加第三层可铺空间。
- 旧版净化符配方仍保留（银1金1），免费单格净化+5且清癌元；策划没有要求移除。后续若要精简旧内容，可从配方表调整。

## 成就实现

成就包括首次铺地、净化5格、同地形连接5格、地形升级、合成元素兽、培养元素动物、建庇护所、抵挡星雨、500灵力、五种元素兽、铺满地图、完成本局全部愿景。

规则层保留本局成就和指标；`achievements.js`只保存本机解锁ID及最高进度。存储损坏或不可用时退回会话内记录，玩法不受影响。成就奖励提示采用现有纸面面板与轻动画，重开会取消旧提示及旧终局定时器。刷新仍然开始新对局，不保存棋盘。

## 验证与使用

规则与几何检查：`npm test`。新增浏览器回归：`npm ci` 后安装 Chromium（`npx playwright install chromium`），再运行 `npm run test:v1-ui`。可以设置 `PLAYWRIGHT_BROWSER_CHANNEL=chrome` 使用已安装 Chrome，或用 `PLAYWRIGHT_BROWSER_PATH`指定测试浏览器路径。

浏览器报告与截图保存在被忽略的 `artifacts/`，不会打包进静态发布。旧 Python 浏览器工具仍保留，其依赖按 `requirements.txt` 安装；`npm run test:browser` 运行旧三组回归，`npm run test:all`同时运行规则、新增UI与旧浏览器测试。

本地预览：`npm run dev`，打开 `http://localhost:8080`。无需构建。Playwright只用于开发测试，线上游戏不需要 npm 包、Python或联网资源。

本次验证细节与局限见 `V1-VALIDATION-2026-10-04.md`。历史发布报告保持原样。
