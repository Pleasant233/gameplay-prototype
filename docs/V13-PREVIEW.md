# v1.3 策划试玩版 / 应用 0.4.0

依据桌面《元素生境_玩法策划案v1.3_剧情与新手引导版》实现，2026-10-10。2026-10-12 已发布正式环境：https://element-habitat.vercel.app 。

## 试玩入口

运行 `npm run dev`，打开 http://localhost:8080/ 。默认“初醒之旅”包含剧情与操作教学；菜单可以重开自由生境、打开回声册和 80 地块图鉴。刷新自动恢复本机存档；换浏览器或换域名不共享存档。

按引导完成前 3 轮，即可体验净化、免费地形升级、连续使用普通结晶和同系列连片。选择地块查看下一层各分支缺少的属性与条件。升级保留现有属性、生物、计时与交互状态。

## 本版交互取舍

教学采用可跳过的指引，不锁死其他合法操作；偏离推荐资源用法后，可通过跳过教学继续经营。河谷能力按固定四邻顺序选取符合条件的邻格，暂未增加逐格勾选器。航运的合法性、距离与容量由规则引擎校验。新地块不是 80 套独立模型，美术替换与升级节奏的人工试玩调参仍待后续进行。

## 自动合兽（2026-10-10）

每轮产出、移动、灾变与容量裁剪结算后，同格每 3 个未交互的同属性元素灵自动免费合成 1 只元素兽，可连续合成多组。先结算本轮结晶，再合成；新兽从下一轮开始计龄、移动和产出。沿用手动合成的统计、成就与记忆，保留手动入口，不自动合成守护灵。已有存档刷新即可生效。

## 自动生态修订（2026-10-10，覆盖上文旧的手动交互）

- 动物无逻辑数量上限，移除移动、喂养、配对、堆肥按钮及规则入口；每只普通动物每轮35%概率在所在地块的正属性中等概率选择一种元素化，不消耗属性。无正属性时不转化。牧场分支概率为45%/55%/65%。新转化动物下一轮开始，每只每轮对应属性+1，受地块上限限制。所有动物直接计分为0。
- 植物保留生态实体，每3轮自动滋养：树/灌木→木+1，水草→水+1，草/作物→土+1。不再手动移植、砍伐或堆肥。矿物轮末自动入背包，每份使所在地块金+1，取消手动采集。
- 删除木桶、净化符、庇护所的制作配方、制作入口与规则处理器。已有背包物品、旧庇护所、结晶、元素盾配比/部署继续可用。庇护所目标改为见证3次动物元素化，避免新局出现无法完成的目标。
- 原依赖动物/采集/制作操作的系列能力改为自动生态触发，详见图鉴：林地提高木滋养；渔场有鱼增水；航道自动迁鱼；河谷扩散水/土滋养；遗迹聚矿增加金。
- 动物在数据中完整保留；桌面每格最多展示12个模型、手机6个模型，详情按物种/元素显示全部真实数量。这是画面展示限额，不限制生成、保存、滋养或计分规则。

结晶兑换/拆晶/逆晶回收配方同样移除：沙漠A在火为正时每轮金+1/2/3；冰原B在水为正时每轮水+1/2/3；湿地B有癌元时每轮土+1/2/3，不消耗背包结晶。
